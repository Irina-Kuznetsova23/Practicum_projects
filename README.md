Визуализация и анализ метрик сервиса доставки еды.
Описание проекта: 
Проанализировать активность пользователей DAU, эффективность конверсии в заказы, удержание клиентов, динамику среднего чека, 
а также вклад популярных ресторанов и блюд в общую выручку. Кроме того, дашборд будет использоваться для выявления трендов и принятия решений по улучшению работы сервиса.
Ключевые слова (DAU, Conversion Rate, средний чек, LTV, Retention Rate, DataLens).
